# 固定目录与产物命名契约

## 目录

1. 顶层结构
2. 结果单元编号
3. 各目录约定
4. 变更与覆盖规则
5. 最终交付映射

## 1. 顶层结构

创建新项目时使用以下结构：

```text
<项目名>/
├── .paper-menu.json
├── 1_数据/
├── 2_代码/
├── 3_图片/
├── 4_表格/
├── 5_参考文献/
└── 6_最终Latex代码+PDF+Word/
    └── 0_论文执行台账.md
```

六个中文目录是固定业务目录。不得改名、调序或在项目根部另建业务目录。`.paper-menu.json` 是机器可读状态，不属于业务目录；执行台账记录用户批准的 Skill 计划、阶段状态和验证证据。

## 2. 结果单元编号

把一次分析或实验定义为一个“结果单元”。同一结果单元的主代码、主图片和主表格共享编号与标签：

```text
2_代码/1_得到描述性统计结果.py
3_图片/1_得到描述性统计结果.png
4_表格/1_得到描述性统计结果.xlsx

2_代码/2_得到处理效应估计结果.R
3_图片/2_得到处理效应估计结果.pdf
4_表格/2_得到处理效应估计结果.csv
```

遵守以下规则：

- 使用正整数连续编号；跨 `2_代码`、`3_图片`、`4_表格` 共用一个结果编号空间。
- 使用 `N_得到<中性结果标签>结果.<扩展名>`。标签说明计算对象，不把假设写成已证实结论。
- 一个结果不需要某类产物时不要创建空占位文件。
- 同一结果需要多幅图或多张表时，在标签中加入可区分且有意义的限定词，并分配新的结果编号；不要用 `final2`、`new`、`最新版`。
- 使用 `plan_result_paths.py --reserve` 分配编号。不得凭记忆手工选择下一个编号。
- 代码必须生成同编号产物；正文、台账或图注应能追溯到该代码和所用数据。

## 3. 各目录约定

### `1_数据`

- 保留原始数据只读副本，记录来源、许可、获取日期、校验值和任何隐私限制。
- 将清洗或派生数据与原始数据区分。推荐使用 `1_原始数据_<来源>`、`2_处理数据_<用途>`，但不要为了改名破坏外部数据引用。
- 不把密钥、访问令牌、受限个人数据或未经许可的全文放入可发布项目。

### `2_代码`

- 每个主分析脚本遵守结果单元命名。
- 固定随机种子、环境和参数；把路径写成相对项目根目录可解析的形式。
- 不把生成的图表或数据混放在代码目录。

### `3_图片`

- 存放可直接用于论文的正式图。优先保留矢量版本，并按目标期刊要求提供栅格版本。
- 图中的数值必须来自同编号代码或可核验外部来源。
- 草图不得冒充最终图；确需保留时使用明确的“草图”标签并在最终审计前清理或升级。

### `4_表格`

- 存放结构化结果表和论文用表；数值精度、单位、样本量、统计量与正文一致。
- 不用截图代替可审计的数据表。

### `5_参考文献`

- 记录检索式、数据库、检索日期、筛选标准和去重过程。
- 至少保留一个最终参考文献库，例如 `.bib`、`.ris` 或经核验的等价格式。
- 对 DOI、题名、作者、年份、卷期和页码做字段级核验；无法核验的条目标记状态，不猜测补全。

### `6_最终Latex代码+PDF+Word`

- `0_论文执行台账.md`：过程与审批记录，不是论文正文。
- `1_论文正文.tex`：唯一最终 LaTeX 主入口。
- `2_论文正文.pdf`：由当前 `1_论文正文.tex` 编译产生。
- `3_论文正文.docx`：与最终稿语义一致的 Word 版本。
- 期刊模板的附属 `.sty`、`.cls` 或补充材料可存放于此，但不得替代三项必交付物。

## 4. 变更与覆盖规则

- 不静默覆盖文件。若要重新生成同一结果，先验证来源，再进行可恢复替换并在台账记录原因。
- 若结果含义变化，分配新编号；若只是无语义变化的格式修复，可保留编号并记录修订。
- 删除、移动或批量改名之前，解析并核对目标绝对路径，检查正文和 LaTeX 引用，再执行。
- 任何专业 Skill 建议的新根目录都要映射到六目录；确有必要偏离时先获得用户批准并更新契约。

## 5. 最终交付映射

最终审计需建立以下链条：

```text
原始数据/文献
  -> 清洗或筛选记录
  -> N_得到XX结果代码
  -> 同编号图片/表格
  -> Results 中的事实陈述
  -> Discussion 中受证据限制的解释
  -> Abstract/Conclusion 中不扩大的总结
  -> 同源 LaTeX、PDF、Word
```

链条中任何一环缺失，都应作为缺口报告，而不是用语言润色掩盖。
